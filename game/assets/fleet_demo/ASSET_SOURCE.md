# 개척선 데모 에셋

- 출처는 프로젝트 사용자가 제공한 `graduate_fleet_map_godot.zip`이다. ZIP SHA-256은 `A8F502BBCFEE0D4F353481C289FEC12A369D2DFF58E9D58DE97FB5EE790F89FB`다.
- `rooms/`의 씬은 텍스처 경로를 이 폴더로 바꿨다. `art/`에서 씬이 참조하는 PNG와 소품 애니메이션을 가져왔고, `layout/`에서 방 배치·소품 애니메이션 데이터를 가져왔다. 캐릭터, 사격, 퓨즈 아이콘과 효과음은 본편 리소스를 사용한다.
