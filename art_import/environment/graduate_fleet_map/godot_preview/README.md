# 개척선 연구실 B동 맵

Godot 4 프로젝트입니다. Godot의 프로젝트 관리자에서 `project.godot`을 가져온 뒤 F5로 프로젝트를 실행합니다. 미리보기는 미카의 방에서 시작합니다.

| 조작 | 동작 |
| --- | --- |
| WASD 또는 방향키 | 이동 |
| E | 가까운 문이나 장비 조작 |
| Tab | B동에서 1~3차 웨이브 스폰 지점 확인 |
| Esc | 종료 |

## 확인할 동선

1. 미카의 방 오른쪽 문으로 비품실에 들어갑니다. 왼쪽 캐비닛을 열고 E를 다시 눌러 정상 퓨즈를 가져옵니다.
2. 비품실 아래쪽 문으로 복도에 나와, 맨 오른쪽에 있는 북쪽 문으로 전기실에 들어갑니다.
3. 전기실 중앙 위쪽의 주 배전함을 열고, 고장 퓨즈를 뺀 뒤 정상 퓨즈를 꽂습니다.
4. 복도로 돌아가 오른쪽 끝의 격벽에서 E를 눌러 연구실 B동에 들어갑니다.
5. B동에서 Tab으로 1~3차 스폰 지점을 순서대로 확인합니다. 오염된 정지 레버를 조작하면 웨이브 위치가 처음 표시됩니다.

이 프로젝트에는 방 이동과 퓨즈 교체를 확인하는 미리보기 로직이 있습니다. 웨이브는 스폰 지점까지 배치되어 있습니다. 실제 전투를 연결할 때는 각 웨이브의 적 종류와 수, 시작·종료 조건을 기존 전투 시스템에서 결정합니다.

## 기존 프로젝트에서 재사용

- `rooms/`에 방마다 편집 가능한 Godot 씬이 있습니다. 바닥, 벽, 소품, 충돌, 전경과 스폰 지점을 각각 편집할 수 있습니다.
- `layout/`의 방 JSON에 출입구 연결, 진입 위치, 소품별 상호작용 키와 충돌 크기가 들어 있습니다. 타일 간격은 48px입니다. 별도 프로젝트로 옮길 때는 `art/`를 포함하고 씬의 `res://art/` 경로를 맞춥니다.
- `research_lab_b.tscn`의 `Wave_1`~`Wave_3` 노드 아래 Marker2D를 기존 웨이브 스폰에 사용할 수 있습니다.
- 소품은 바닥에 닿는 부분을 기준으로 정렬하고, 충돌 크기는 필요한 바닥 면적에 맞춥니다. 스프라이트의 투명 여백이나 높이는 충돌에 포함하지 않습니다.
