# 개척 탐사선 연구 구역

탐사선 내부용 ¾ 탑다운 픽셀 스프라이트와 배치 예시입니다. 바닥과 장식용 배관은 48×48px, 북쪽 벽면 패널은 48×96px입니다. 소품은 개별 크기의 투명 PNG입니다. 확대할 때는 최근접 필터를 사용하세요.

## 에셋

| 구성 | 파일 또는 폴더 |
| --- | --- |
| 손전등, 전기 안전장치, 스테이지 격벽, 정비대, 대형 화면, 경고등, 탄약함, 보관함, 캐비닛, 터치패널 | `sprites/props/` |
| 일반·침식 코어, 침식된 안전장치, 침식 흔적, 침상, 선반 | `sprites/props/` |
| 일반·침식 벽면과 바닥, 환기구 바닥, 통로 표식 | `sprites/tiles/` |
| 세로, 가로, U자, 네 방향 직각 배관 | `sprites/pipes/` |
| 미닫이 캐비닛 열림 5프레임, 적색 경고등 점멸 4프레임 | `animations/` |
| 4방향 출입구, 위쪽 문 열림 및 닫힘 | 아래 **스테이지 이동 문** 참조 |
| 파일 경로, 크기, 기준점, 배관 연결 방향과 프레임별 시간 | `assets.json` |

캐비닛은 왼쪽 문짝이 오른쪽으로 이동해 내부가 드러납니다. 닫을 때는 `close_order`에 적힌 역순으로 재생합니다. 경고등은 800ms 주기로 점멸합니다. 애니메이션 PNG는 한 줄이며, 프레임 크기와 시간은 `assets.json`에 있습니다.

## 방 배치

| 방 | 배치 |
| --- | --- |
| `research_lab` | 왼쪽 정상 코어와 안전장치, 정면 스테이지 격벽, 오른쪽 침식 코어와 격리 구역 |
| `supply_room` | 중앙 통로, 벽면 선반과 열린 캐비닛, 양쪽의 탄약함과 보관함, 손전등 |
| `gunsmith_quarters` | 왼쪽 정비대와 화면, 오른쪽 침상과 개인 수납 |

`rooms/`에 방별 완성 이미지와 같은 이름의 JSON이 있습니다. JSON의 타일 좌표는 좌상단 기준 0부터 시작합니다. `floor_tiles[y][x]`의 값은 `assets.json`의 스프라이트 ID와 같습니다. `top_left_px`는 완성 이미지 안의 배치 좌표입니다. `pivot_world_px`는 `assets.json`의 `pivot_px` 기준점을 방 이미지에 배치한 좌표입니다. `blocked_tiles`는 통행을 막는 타일이며, `approach_cell`은 해당 소품에 다가가 조작할 위치입니다.

연구실 왼쪽 출입구는 비품실, 오른쪽 출입구는 개인실로 이어집니다. 정면 격벽의 `next_stage`와 아래 출입구의 `ship_corridor`는 게임의 실제 씬과 연결하세요.

## 스테이지 이동 문

| 문이 놓인 벽 | 닫힌 스프라이트 ID | 애니메이션 PNG | 프레임 크기 |
| --- | --- | --- | --- |
| 위 (`n`) | `stage_door` | `animations/stage_door.png` | 122×118px |
| 왼쪽 (`w`) | `stage_door_west` | — | 28×104px 정지 스프라이트 |
| 오른쪽 (`e`) | `stage_door_east` | — | 28×104px 정지 스프라이트 |
| 아래 (`s`) | `stage_door_south` | — | 96×16px 정지 문턱 |

위쪽 문 시트는 6프레임이 한 줄에 들어 있습니다. 열기는 `0 → 5`, 닫기는 `5 → 0` 순서이며, 한 번 재생하는 데 340ms가 걸립니다. 좌우 문은 세로 벽 두 칸 사이에 가운데 기준점을 맞춰 배치합니다. 프레임 시간, 기준점, 암전 설정은 `assets.json`의 `animations`, `stage_transition` 항목을 사용하세요.

1. 플레이어가 `approach_cells` 중 한 칸에서 상호작용하면 이동과 중복 조작을 잠급니다. 위쪽 문은 열기 시작 160ms 후부터 180ms 동안 암전합니다. 좌·우·아래쪽 출구에서는 즉시 암전을 시작합니다.
2. 화면이 검게 변하고 출발 문 애니메이션이 끝나면 `target_room`으로 이동합니다. 도착 위치는 도착 출입구의 `arrival_cell`입니다. 예시 방끼리는 `target_exit_edge`와 `target_spawn_cell`에 연결 정보가 들어 있습니다. 외부 씬에 연결할 때는 해당 씬의 도착 출입구를 지정하세요.
3. 위쪽 문으로 도착할 때는 암전 중 열린 프레임 `5`를 표시합니다. 180ms 동안 화면을 밝힌 뒤 위쪽 문을 닫고 조작을 풀어 줍니다. 정지 출입구로 도착하면 화면이 밝아진 뒤 바로 조작을 풉니다.

`trigger_cell`은 벽에 맞닿은 출구 타일이고 `approach_cells`는 실내에서 조작할 수 있는 타일입니다. `door_top_left_px`에서 스프라이트와 애니메이션 시트를 동일한 위치에 표시하면 됩니다. `door_animation`이 `null`이면 해당 출입구의 애니메이션 단계를 건너뜁니다.
