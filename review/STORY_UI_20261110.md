이후 실제 게임 루프를 켠 검사에서 서사 경과시간(elapsed)이 바뀌는 것만으로 정상 답변이 stale_facts로 폐기되는 오류를 확인했다. 저장/연출용 시계는 유지하되 대화 사실 비교에서는 제외했고 회귀 검사를 추가했다. 물품 질문에는 다음 행동보다 대상 물품의 이름/원래 위치/현재 위치/획득·장착 상태를 우선한다. ‘그럼 지금은?’ 같은 다음 단계 질문은 현재 진행을 우선한다.

수정 후 새 격리 실행의 실제 Qwen3 통합은 **5/5**, 불러오기 취소/재질문은 **7/7**, 모두 종료 0이다. 실제 원문 예시는 다음과 같다.

- ‘지금 무엇을 해야 해?’ → ‘오른쪽 통로에서 손전등 받으려고 해. 빨리 가자.’ (36.71초). 손전등/오른쪽 안내는 맞지만 ‘받으려고 해’의 행동 주체가 어색한 한계가 있다.
- ‘보관 구역에서 찾아야 할 물건이 뭐야?’ → ‘퓨즈야. 보관 구역 북동쪽 보관함에 있어. 빨리 빌려야지.’ (16.12초). 물품·위치는 맞고 실제 말풍선/복원된 기록에 반영됐다. ‘빌려야지’는 상황에 맞지 않는 어휘다.

기존 실제 패널/손전등 검사는 11/11, 추가 비동기/긴급 치료·장전/재추론·취소 검사는 8/8 통과했다. 이 두 결과는 앞선 실행의 변경되지 않은 실행기/전송 경로 증거이며 시점과 원문을 별도 보존한다. 비동기 검사에는 의도적으로 줄인 클라이언트 제한시간이 포함된다.

**전체 -LocalAI의 최종 통과로 보고하지 않는다.** 전체 문답 검사에서는 생성 토큰 상한 도달과 대화 품질 실패를 재현했고, 사용자 모델 비교 요청에 따라 해당 실행을 중단했다. 최종 핵심 경로는 6장면 추가 호출과 위 개별 실제 회귀로 확인했다. 실패/취소/원문/실제 제공자를 보존했고 템플릿이나 다른 모델의 성공으로 대체하지 않았다.
