# 본편 대화·하린 이동·협동 보관함·손전등

2026-11-07 사용자 요청의 다섯 항목을 본편 `res://main.tscn`에 적용했다. 화면 자동 조작과 보이는 검사 창은 사용하지 않았다. 기존 작업·증거·저장 슬롯은 보존한다.

후속 변경: 손전등은 아래 최초 구현의 이동 방향 대신 **마우스 조준 방향**을 따른다. 빈 Enter/전송 Enter/Esc로 대화를 닫으며 주요 장비·가구에 플레이어 충돌을 추가했다. 사용자가 후속 작업에서 실제 창 확인을 별도로 허용했다. 최신 동작·검증은 `INPUT_AIM_COLLISION_20261107.md`를 따른다. 아래 내용은 최초 다섯 항목의 구현 기록이다.

## 플레이 흐름

1. 연구실 오른쪽 통로에 다가가거나 E로 진입을 시도하면 하린이 다가와 손전등을 바닥에 떨어뜨린다. 가까이에서 E로 줍기 전에는 암전 구역에 들어갈 수 없다. NPC와 물품이 가까우면 줍기를 우선한다.
2. 보관 구역은 기존 원형 시야에 이동 방향의 부채꼴 빛을 더한다. 멈춰도 마지막 이동 방향을 유지하며 마우스 조준 방향과는 별개다. 기본 길이 390, 반각 32도이며 경계와 원거리 빛을 부드럽게 감쇠한다.
3. 적을 제압해도 일러스트 대화창은 열리지 않는다. 말풍선과 선택적으로 여는 대화 기록을 사용한다. Enter로 높이 56의 작은 입력창을 열고, Enter 전송 후 입력을 비우고 닫는다. Esc는 미전송 초안을 보존하며 닫는다. 기존 ChatInput·IME·LLM 연결을 재사용한다.
4. 북동쪽 보관함의 패널 A/B 중 하나에 가까이 서서 E를 유지한다. 하린은 규칙/LLM 정책이 `assist_panel`을 선택하면 반대편으로 이동한다. 각각 자기 패널에서 **1초** 유지해야 한다. 일찍 E를 놓거나 범위 밖으로 나가거나 입력창을 열면 진행을 초기화한다.
5. 유지 완료 후 세 쌍의 비프음(6회)이 약 1초 동안 울리고 보관함이 열린다. 완료된 유지 단계는 E를 놓아도 취소되지 않는다. 퓨즈와 1회용 탄약 보급을 회수한다.
6. 퓨즈를 연구실 전력 장치에 장착하면 보관 구역 전체 조명이 켜진다. 다시 보관 구역으로 가거나 저장을 불러와도 암전되지 않는다. 탐색 미니맵도 전체를 표시한다.

하린이 전투 불능이면 두 패널을 작동할 수 없어 이전 저장/새 회차 안내를 표시한다. 부활·솔로 우회·두 실제 플레이어의 본편 협동은 이번 범위에 추가하지 않았다.

## 하린 이동

- `companion_motion.gd`: 가속·감속·도착 감속, 진행 방향에 따른 후방 사선 동행, 일정 주기의 좌우/넓은 간격 전환, 전투 중 측면 엄호, 가까울 때 길 비켜주기, 적 근접 시 거리 확보, 멀어졌을 때 따라잡기.
- 난수 대신 같은 시간 주기와 관측 상태를 사용한다. 도착 데드존으로 떨림을 줄인다. 치료/보급/장비/패널/손전등 전달은 목적지 이동을 우선한다.
- World의 `npc_role`: 원거리 엄호(기본), 측면 지원, 근접 선행. 미래 무기에 연결할 이동 프로필이며 실제 근접 무기·무기 선택은 아직 구현하지 않았다.
- 후방 간격에서도 엄호하도록 NPC 사거리 기본 260을 노출했다. 피해 25·발사 간격 1초·탄약 등 나머지 공통 수치는 유지하고 두 판단 방식에 같은 값을 적용한다.
- 복잡한 가구 경로 탐색은 아직 없으며 현재 열린 방과 벽 범위 안에서 이동한다.

## 기믹·판단·저장

- `CooperativeLocker.tscn`과 `cooperative_locker.gd`로 분리했다. 이후 임무에 재사용할 때 월드/대상 참조를 연결한다.
- 공통 후보 `assist_panel`을 추가했다. NPC를 강제로 성공시키는 LLM 대체 경로는 없다. 실제 이동·거리·E 유지·시간·물품 생성은 공통 게임 규칙으로 검사한다.
- 정적인 패널 판단은 최대 8초의 반환 시간을 허용하되 실행 직전 현재 요청을 다시 검사한다. 기존 전투 판단의 짧은 유효 시간은 유지한다.
- 패널 요청·유지 시작/완료·중단, 지원 시작/완료/거부, 비프/열림, 물품 회수와 전력 복구를 기존 이벤트 로그에 남긴다. 수락·실제 성공·소요 시간을 구분한다.
- 행동 판단에는 체력·탄약·자원·적 수·패널 등의 공통 관측을 추려 전달한다. 규칙 기반도 같은 관측을 받는다. 좌표·장문의 장소 설명은 행동 선택에서 제외하고 대화에는 별도의 상태/규칙 문맥을 사용한다.
- 손전등·조명·보관함·보급·마지막 이동 방향을 저장한다. 1초 미완료 입력은 불러온 뒤 다시 시작하며, 유지 완료 후 비프/해제는 중복 없이 이어간다.
- 스키마 v2. 현재와 전투 설정이 일치하는 v1은 메모리 사본에서만 변환한다. 손전등을 지급하고 이미 퓨즈를 얻었다면 보관함을 연 상태로 복원한다. 원본 슬롯을 자동으로 덮어쓰지 않는다. 전투 설정이 다른 저장은 거부한다.
