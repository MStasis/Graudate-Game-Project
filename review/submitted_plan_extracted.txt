연구 개요
• 기존 게임의 NPC(Non-Player Character) 와의 상호작용은 개발자가 미리 작성해 둔 스크립트에 의존하고 있어, 플레이어의 다양한 행동과 실시간 게임 상황을 유연하게 반영하기 어렵다.
• LLM 모델의 API 호출에 따른 비용 및 지연 시간 문제를 해결하기 위해, PC 로컬 환경에서 독립적으로 구동되는 경량 언어 모델(sLLM)을 게임 클라이언트에 접목하는 시스템을 제안한다.
이를 통해 플레이어의 상태와 게임 진행을 실시간으로 인지하고, 상황에 맞는 자연스러운 대사를 동적으로 생성하여 플레이어의 몰입감을 극대화하는 NPC 시스템을 구현하고자 한다.
연구 목적
• 비용 및 의존성 문제 해결 : LLM API 사용 시 발생하는 비용 문제와 네트워크 의존성을 없애고, 개인 컴퓨터 환경에서도 동작하는 온디바이스 AI 환경을 게임 내에 구현한다.

2. 논문의 개요
서론
• 기존 비디오 게임의 NPC 상호작용은 정적 스크립트에 의존하여 유저의 다양한 행동을 반영하기 어렵고, LLM(API) 도입 시에는 통신 지연과 지속적인 비용 문제가 발생한다.
• 이를 해결하고자 NPC의 대화에 언어 모델을 사용하며, LLM API 호출에 따른 비용 및 지연 시간 문제를 해결하기 위해, PC 로컬 환경에서 구동되는 경량 언어 모델(sLLM)을 게임 클라이언트에 접목하는 것을 목표로 한다.
• 모델 양자화와 비동기 스트리밍 등을 적용하여 일반적인 PC 사양에서도 응답속도 저하 없이 실시간 답변 생성이 가능할 것으로 기대한다.
본론
• 로컬 AI 구현하고 데이터 수집 및 변환을 위한 파이프라인 구축, 빠른 답변 생성을 위한 시스템 을구축하여 실제 게임 프로토타입 내에서 실행까지 진행하는 것을 목표로 한다.
• 결과 분석 : LLM API를 이용한 경우와 sLLM 로컬 모델을 사용했을 경우의 속도와 AI의 성능(추론 능력)을, 자원(메모리)사용량을 중심으로 장•단점을 비교하고자 한다.
결론
• 일반적인 컴퓨터 환경에서도 작동하는 로컬 AI를 최적화하여 게임 시스템에 도입하는 것을 목표로 한다.
• 소규모 게임 개발 환경에서도 무리 없이 온디바이스 형태의 AI NPC를 도입할 수 있는 가이드라인을 제시할 수 있을 것으로 기대한다.
