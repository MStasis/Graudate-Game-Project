# 연구동 외곽 봉쇄 데모 (2026-11-10)

새 게임의 정전/퓨즈 튜토리얼에서 연구동 외곽 봉쇄와 데모 결과 화면까지 연결했다. 연구소 전체의 이상현상 해결은 완료 범위가 아니다. 현재 로컬 파일이 기준이며 커밋/푸시는 하지 않았다. 착수 시 `main` 작업 트리는 깨끗했다.

## 진행과 조작

정전 → 하린 호출 → 손전등 E → 보관 구역 드론 3기 → 기존 2인 패널 E 1초 유지/비프 → 퓨즈 E → 연구실 복귀/전력 장치 E → 침식 경보 → 연구동 출발 문 E → 관측 단말 E → 왼쪽 봉쇄 보급함 E → 중앙 봉쇄 장치 E → 첫 무리 2기 → 둘째 무리 3기 → 최종 2인 봉쇄 패널 E 1초 유지/비프 → 경보 해제/하린 고정 마무리 → 6초 뒤 데모 결과.

`START_DEMO.cmd`로 AI 서버 없이 규칙 기반 실행이 가능하다. WASD 이동, 마우스/Space 사격, E 상호작용, Enter 대화, Esc 닫기/일시정지, M 지도, H 통합 기록을 유지했다. 최종 패널은 한쪽 E를 유지하면 고정 공통 실행기로 하린이 반대쪽으로 이동한다. 하린 대기 시 `따라와` 전송, 다운 시 가까이 E로 키트 1개를 사용한다. 사망 후 F3의 기존 새 회차 버튼, 완료 후 결과의 `다시 시작`을 사용한다. 결과의 `종료`는 게임을 끝낸다.

## 구현 경계

- `containment_mission.gd`/`ContainmentMission.tscn`: 관측 전/준비/첫 전투/두 번째 전투/패널 대기/완료를 명시적으로 관리한다. 기존 `Drone.tscn` 풀, 기존 방/가구/상호작용/협동 실행기를 재사용한다. 첫 무리 전멸 시에만 둘째 무리가 나오고 둘째 전멸 뒤에만 최종 패널을 허용한다.
- `first_wave_count`/`second_wave_count`는 각각 1~6, 기본 2/3이다. 새 드론은 기존 기본 체력 50, 피해/속도/공격 간격을 사용한다. 이동 가능 격자의 출현 후보에서 플레이어/하린/가구/다른 출현점과 떨어진 위치를 선택한다. 조절 값과 연구동 전투 규칙을 시나리오 해시에 기록한다. 난이도 적절성은 사람 플레이 전에는 확정하지 않는다.
- 튜토리얼 `Enemies`/`Locker`와 봉쇄 적 풀/패널/보급은 각각 별도 상태다. 반복 단말·가동·패널 완료는 중복 진행하지 않는다. 이번 봉쇄 적만 전멸 기준으로 사용한다.
- 봉쇄 보급함은 장치 가동 전에 한 번 회수한다. 양쪽 탄약, 하린 예비탄, 공용 키트/보급/보호를 기존 최대치까지 보충한다. 자동 부활이나 무한 탄약은 없다. 기존 긴급 치료/보급·장전·소생·자원 소진 실패를 유지한다.
- 두 전투 중 복귀문은 안전 격리로 잠기며 문/상호작용에 이유를 표시한다. 전투 전/전멸 후에는 왕복할 수 있으며 보급·적·패널 진행은 보존한다.
- `world.is_combat_area()`는 보관 구역/연구동만 전투 구역으로 판별한다. 연구실 사격/피해를 열지 않았다. 연구동 드론은 몸 반경에 맞춘 22px 여유의 20px A*와 마스크 5로 가구를 우회한다. 연구동 탄환은 마스크 7로 가구에 막히며 하린도 가림 뒤로 사격하지 않는다. 기존 보관 구역의 이동/탄환 판정은 보존한다.
- `CooperativeLocker`는 방/용도를 매개변수로 받아 최종 패널에 재사용한다. 실제 접근 가능한 가구 바깥에서도 두 캐릭터가 같은 48px 사용 반경을 적용한다. 동시 1초 유지와 세 쌍의 비프는 유지한다. 최종 패널은 AI 응답이 필요 없다. 먼저 시작한 치료/보급이 끝나면 패널 지원을 고정 실행기로 이어 가는 경계도 검사했다.
- 완료는 `finished`/`escaped`와 연결한다. 생성/공격/탄환/지원/진행 중 AI 요청을 중단하고 경보를 해제한다. 고정 하린 마무리 후 결과에 ‘데모 완료’, ‘연구동 외곽 구역 봉쇄 성공’, 내부 후속 조사 문구와 두 버튼을 표시한다. 다시 시작은 서사/적/보급/양쪽 패널/대화 기억/지도/통합 기록을 초기화한다.
- 자유 대화/제공자 선택은 유지한다. 임무 사실에 봉쇄 단계/완료 사건/다음 목표/적 수/보급을 연결하며, 고정 사건과 공통 실행기를 모델 생성/판단 성공으로 기록하지 않는다. 새 장치와 알림은 발견 지도/통합 기록에 연결한다.
- 저장 v3를 선택 필드로 확장했다. 무리별 적 체력/위치/공격 대기, 단계, 일회용 보급과 별도 패널의 비프 확인을 보존한다. 유지 중이던 시도는 불러오기 때 취소하고 비프에 진입한 절차는 재개한다. 이전 v1/v2/v3와 companion_rules 이전 호환 해시를 정확히 대조해 메모리 사본만 보완하며 원본 파일은 쓰지 않는다. 단계와 사건/살아 있는 적/패널이 모순되면 불러오기를 거절한다.

## 검증 환경과 명령

화면 자동 조작/새 보이는 창을 사용하지 않았다. 현재 동봉 Godot 4.7.2를 사용하고 `runtime/containment_20261110/`에 game(.godot 제외), 검증 스크립트와 같은 실행 파일을 복사했다. 각 실행은 격리 APPDATA와 테스트 전용 저장 디렉터리를 사용한다. 기존 사용자 저장은 검사용으로 덮어쓰지 않았다. 기존 증거는 보존한다. 최초 짧은 헤드리스 스모크는 기존 `evidence/mission_v1/npc_events.jsonl`에 회차 시작 2줄을 추가했고, 이후 검사는 모두 격리 복사본에 기록했다.

```powershell
# 저장소 루트에서 격리 복사본의 전체 기본 + 숨김 GPU
.\runtime\containment_20261110\scripts\verify_mission.ps1 -Render

# 준비된 기존 qwen3:4b/Ollama로 전체 LocalAI 회귀
.\runtime\containment_20261110\scripts\verify_mission.ps1 -LocalAI

# 마지막 저장 호환 보완 뒤 봉쇄 검사만 재실행
# 같은 복사본에서 --headless --script res://tests/containment_test.gd
# GPU는 Start-Process -WindowStyle Hidden, Dummy 오디오,
# --script res://tests/containment_test.gd -- --render-containment
```

`scripts/verify_mission.ps1`은 봉쇄 기본/Render/LocalAI 검사를 각각 포함한다. 결과 JSON의 passed/check_count/생성 시각과 프로세스 종료를 확인한다. 현재 검사 원문과 최종 JSON/PNG는 `evidence/containment_demo_20261110/`에 보존한다.

기본 합계는 **653/653**(539+114), GPU 합계는 **501/501**(382+119)이다. 최초 전체 Render 실행 이후 이전 v3 호환·손상 방어·마무리 대사 표시·지원 후 패널 재개 검사를 보완해 봉쇄 suite를 각각 재실행했다. 마지막 봉쇄 프로세스와 전체 Render 프로세스는 종료 0, 루트 최종 import는 종료 0/파싱·컴파일 오류 0, `git diff --check`도 통과했다. 현재 변경 소스 26개와 격리 복사본의 SHA-256이 모두 일치했다. 마지막에는 검사 서버를 종료한 상태에서 규칙 기반 봉쇄 114/114를 다시 확인했다(`offline_final.log`, 종료 0). 실행 시각/검사별 결과는 JSON과 `summary.json`을 따른다.

전체 LocalAI는 다음 두 표현 검사에서 실패해 이후 suite를 자동 중단했다. 기준을 느슨하게 바꿔 통과시키거나 모델 답을 고정 대사로 대체하지 않았다.

- `mission_answer_has_current_goal`: ‘오른쪽 통로 손전등 빌려야 돼’라고 답했으나 기존 검사가 요구하는 ‘받/수령/챙’ 표현이 없었다. 손전등이라는 방향성은 맞지만, 테스트의 표현 기준은 미충족이다. 답 뒤에는 임무에 불필요한 식사 언급도 붙었다.
- `latest_state_overrides_old_history`: ‘네, 지금 손에 있어’라고 답해 소유자를 명시하는 ‘네 손/네가/너한테’ 기준을 만족하지 못했다. 반말 설정과 명확한 지칭도 추가 평가가 필요하다. 이 결과만으로 잘못된 소유자를 단정하지 않는다.

서사 원문에는 근거 없는 교대 잔여 시간 추측과 반복 반문도 관찰됐다. 따라서 전체 LocalAI/일반 대화 자연스러움 통과를 주장하지 않는다. 봉쇄의 필수 안내/전투/패널/엔딩은 고정 사건과 공통 실행기이므로 이 생성 결과가 진행 조건이 되지 않는다. 자동 중단 이후 최종 소스의 봉쇄 실제 취소 7/7과 기존 전술 통합 5/5를 별도로 확인했다. 전술 통합은 실제 치료·보급 효과, 추론 중 이동, 방 이동 후 낡은 응답 폐기와 경로 응답을 검사한다. 이번 검사에서 시작한 Ollama 서버만 확인 후 종료했다.

## 한계와 남은 사람 확인

- 자동 흐름은 위치 이동과 경계 fixtures, 일부 적 정지/직접 상태 설정을 사용한다. 실제 탄환 적중·이동·접촉 피해·하린 사격/장전·가구 우회·패널 접근은 별도로 실행했지만 **사람이 새 게임부터 완주한 결과가 아니다**.
- 사람은 `START_DEMO.cmd`로 새 게임부터 WASD/조준/사격/E/소생/재시작을 조작해 끝까지 진행해야 한다. 드론 2/3기, 자원 여유와 이동 공간의 난이도를 확인하고 필요하면 무리 수를 조절한다.
- 실제 Microsoft IME, 실제 청취, 장시간 안정성, export/다른 PC, 실제 두 PC LAN은 미검증이다. 이번 기능은 싱글플레이+하린이며 본편 협동 완료가 아니다.
- 실모델 호출/취소와 대사 의미/자연스러움을 구분한다. 추론 지연과 자유 대화의 잘못된 추측은 별도 품질 과제다. 필수 진행은 모델을 기다리지 않는다.
- 전체 GPU 실행의 기존 하린 검사 종료(8 ObjectDB/2 리소스)와 최종 봉쇄 GPU 종료(4 ObjectDB/2 리소스)에 정리 경고가 남았다. 프로세스는 종료 0이고 검사/PNG는 통과했지만, 장기 안정성과 종료 자원 정리를 보장하지 않는다. stderr를 함께 보존한다.

새 그림/음향은 만들거나 다운로드하지 않았다. 기존 임시 Kenney 자산과 UI를 재사용하며 출처/CC0/해시는 `game/assets/temporary/kenney/`를 따른다.
