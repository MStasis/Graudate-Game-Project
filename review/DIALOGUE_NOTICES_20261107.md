# 하린 대화와 시스템 알림 분리

2026-11-07 후속 요청과 전송 후 이전 입력이 남는 문제를 수정했다. 로컬 작업 시작 시 527개 기존 파일의 해시·git status·원본 game 사본을 `runtime/dialogue_notices_20261107/`에 보관했다. 기존 사용자 변경·저장 슬롯·증거는 보존한다. 컴퓨터 유즈는 다시 켜지 않았다.

작업 중 기존 게임 실행 6760이 원본 로그에 기록을 추가하고 IME bridge 상태를 갱신했다. 로그의 기존 바이트는 시작 해시와 일치하며, 추가된 사용자 기록도 되돌리지 않고 유지했다. 상세 보존 감사는 새 증거 폴더에 있다.

## 달라진 표시

- 시스템 상호작용 결과·E키/1초 유지 안내·획득/회복 수치·연결 오류는 플레이어 오른쪽 알림으로 표시한다. 약 3.2초 표시 중 마지막 0.9초에 투명해지고 최대 3개를 유지한다. 화면 가장자리에서는 화면 안으로 보정한다. 입력 포커스/사격을 가로채지 않는다.
- `world.notice`는 시스템, `world.companion_spoke`는 실제 캐릭터 대사다. 시스템 문구는 하린의 Answer/말풍선/대화 기록을 덮지 않는다. 자동 판단/모델 준비의 개발 상태는 반복 게임 알림으로 내보내지 않는다.
- 패널 지원은 “내가 반대편 누를게!”, 손전등 지급은 “여기 놨어. 챙겨 가.”로 말한다. E키·유지 시간·체력 수치는 별도 알림이다. 응답 대기나 오류도 하린이 말한 문장처럼 표시하지 않는다.
- 전송한 문장은 연구실/보관 구역 모두 비운다. Enter로 다시 열면 빈 입력칸이다. 미전송 초안을 Esc로 닫는 동작과 IME 확정/검증 경로는 유지한다.

## 대화와 사실

- `harin_dialogue.gd`가 잡담과 구체적인 임무 질문의 문맥을 나눈다. 잡담에는 목표·전체 기믹 매뉴얼과 이전 임무 대사를 넣지 않는다. 안부/음식/감정에 맞는 짧은 대화 방향을 제공한다. 규칙 기반의 인사·식사·불안·감사 응답도 질문별로 나눴다. “질문이 있어”를 문/임무 질문으로 잘못 분류하던 부분도 고쳤다.
- 구체적인 질문에는 최신 소지자·위치·역할과 공통 정책의 의미 기준을 제공하고 Qwen3가 표현을 생성한다. 손전등이 하린 손/연구실 바닥/플레이어 손 중 어디에 있는지 구분한다. 이미 주운 물품을 다시 주우라고 하는 과거 대사 혼입을 줄이기 위해 기믹 질문에는 이전 생성 답변을 사실로 재사용하지 않는다.
- 조작법을 물었을 때만 키/유지 시간을 제공한다. 손전등 질문에 패널 매뉴얼 전체를 붙이지 않는다. 모델 응답을 출력 후 잘라내거나 규칙 문장으로 몰래 교체하지 않는다. 실패를 다른 제공자의 성공으로 기록하지 않는다.
- 프롬프트 버전 `companion_v1.12_conversation`, 로그 방식 `state_grounded_generation_structured`. 실제 Qwen3 4B/생성 옵션은 유지한다. 전투 판단 후보·우선순위·공통 실행기·자원 수치는 변경하지 않았다.

## 검증

기존 미커밋 증거를 덮지 않도록 `runtime/dialogue_notices_20261107/check/`와 독립 APPDATA에서 검사한다. 최종 결과·실행 시각·로그·원문·PNG는 `evidence/dialogue_notices_20261107/summary.json`을 따른다.

최종 통과: 기본 373/373, GPU UI 81/81·기믹 56/56·입력/조준/충돌 35/35·대화/알림 35/35, 자동 임무 완료. 실제 Qwen3는 기존 지원 5/5·저장 취소 7/7·기믹 11/11·새 대화 20/20(10응답)을 확인했다. 마지막 수정은 방향 질문 인식과 전술 응답 처리의 들여쓰기를 고친 것으로, 이후 전체 LocalAI 모드를 다시 실행했다. GPU는 동일한 UI 코드의 Render 실행 결과다.

```powershell
.\scripts\verify_mission.ps1 -Render
.\scripts\verify_mission.ps1 -LocalAI
```

새 기본 검사는 알림 우측 배치/화면 경계/페이드/만료, 캐릭터 대사와 기록 보존, 오류/대기 분리, 짧은 실제 지원 대사, 잡담 문맥과 기믹 상태, 전송 후 입력 초기화를 확인한다. GPU는 생성 PNG를 확인한다. 손전등 픽셀 검사는 알림이 빛 표본을 가리지 않게 UI를 먼저 지운 뒤 기존 방향/감쇠 판정을 유지한다.

실제 모델은 인사·음식·불안·일반 질문·손전등 3상태·패널 제안/조작·임무 대화 뒤 잡담의 10개 개발 사례를 확인한다. 초기 잘못된 상태 설명과 개발 중 실패도 별도로 보존한다. 이 점검에 맞춰 프롬프트를 보완했으므로 정식 비교 실험이나 독립적인 자연스러움 평가로 사용하지 않는다. 질문 되묻기·반복 표현 같은 문장 품질에는 여전히 모델 편차가 있어 사람 평가가 필요하다.

사람의 전체 플레이·실제 Microsoft IME 조합·청취·두 PC LAN은 이번 검사에 포함하지 않는다. 화면 자동 조작/화면 캡처 도구도 사용하지 않았다.
