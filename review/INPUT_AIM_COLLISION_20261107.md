2026-11-07 후속 요청 세 항목을 본편에 적용했다. 작업 시작 시 482개 기존 파일의 해시·git status와 `game/` 사본을 `runtime/input_aim_collision_20261107/`에 보관했다. 기존 사용자 저장·증거를 검사용으로 덮어쓰지 않았다.

- **채팅:** 연구실/보관 구역 모두 빈 Enter·공백 Enter·키패드 Enter는 전송 없이 닫는다. 정상 메시지는 전송 후 닫는다. Esc는 미전송 확정 문장을 보존하며 닫고, 조합 중에는 조합을 취소하고 닫는다. 닫은 뒤 이동으로 돌아가고, 다음 Esc는 기존 일시정지다. 응답 대기 중 열었던 읽기 전용 창도 닫을 수 있고 추론은 취소하지 않는다. 300자 제한과 중복 전송 방지는 유지한다.
- **입력 경로:** 실제 OS 입력 검사에서 Enter의 일반 키코드와 스캔코드가 다르게 전달되는 것을 확인했다. `main.gd`의 UI 명령은 일반 키코드를 우선한다. 합성 회귀에도 키코드가 다른 경우를 포함했다.
- **손전등:** `world.gd`가 마우스 화면 좌표를 현재 CanvasLayer 변환의 역행렬로 게임 좌표에 바꾼다. 클릭 사격과 같은 조준 기준이며 정지·옆걸음·카메라 이동 중에도 갱신한다. 마우스가 플레이어 중심이면 마지막 유효 방향을 유지한다. 원형 근접 시야·거리/각도 감쇠와 전력 복구 후 전체 조명은 보존한다. CPU 탐색/HUD와 GPU가 같은 방향을 사용한다. 하린 이동 대형은 계속 이동 방향을 사용한다.
- **충돌:** `rounded_obstacle.gd`의 둥근 볼록 다각형과 기존 플레이어 원형 발밑 판정·`move_and_slide()`를 사용한다. 전력 장치, 패널 A/B, 협동 보관함, 비상 탄약함, 연구 콘솔, 연구실 장비 보관함/분석 장치, 보관 구역 선반 2개/배관 등 11개다. Inspector에서 footprint와 corner_radius를 조정할 수 있다. 숨겨진 방/소진된 물체는 충돌도 꺼진다. 출구·통로·떨어진 물품은 계속 접근 가능하다.
