# 1단계 — LAN 협동 검증과 임시 에셋

2026-11-06. 사용자 결정: **LAN 목표, 지연 시 싱글 완성 우선 / 무료 에셋만 / SF 분위기 우선**. 이후 화면 조작 중단 요청을 반영해 백그라운드 검사만 진행한다.

## 구현

- `game/scenes/CoopProbe.tscn`, `game/scripts/coop_probe.gd`: 메인 임무와 분리된 2인 검증 전투실. ENet 호스트 1명 + 클라이언트 1명, 직접 IP/포트 접속, 끊기/재접속, 표적·탄약 초기화.
- 호스트가 기존 `Player.tscn`의 이동 물리와 `Projectile.tscn`의 레이 적중을 실행한다. 클라이언트는 입력만 보내며 호스트가 송신 peer ID로 조작 대상을 결정한다. 클라이언트 그림/탄환 흔적은 표시용이고 피해를 계산하지 않는다.
- 입력은 20Hz 전송, 서버 물리는 물리 프레임마다 계산, 결과는 20Hz 전달한다. 오래된 시퀀스와 비정상 수치를 거부하고 이동 벡터 크기를 제한한다. 350ms 이상 입력이 없으면 이동·사격을 멈춘다.
- 짧은 마우스 클릭/Space를 전송 간격까지 보관한다. UI 클릭은 사격하지 않는다. 탄약·발사·실제 적중·표적 체력을 양쪽에 표시한다.
- 재접속은 이전 캐릭터를 남기지 않고 현재 표적 상태를 받는다. 호스트 종료/접속 실패는 접속 메뉴로 돌아간다.
- Kenney Top-down Shooter / Sci-fi Sounds의 선택 파일을 메인 임무와 검증 씬에 적용했다. 출처·CC0 원문·ZIP/파일 해시는 `game/assets/temporary/kenney/`에 있다. 기존 그림·UI 초상화·전투 수치·충돌 크기는 보존했다.

## 실행

```powershell
.\START_COOP_TEST.cmd                    # 접속 화면
.\scripts\start_coop.ps1 -HostGame       # 호스트 창
.\scripts\start_coop.ps1 -JoinAddress 127.0.0.1 # 같은 PC의 두 번째 창
# 다른 PC에서는 127.0.0.1 대신 호스트의 LAN IP를 입력한다.
.\scripts\verify_coop.ps1                # 실제 두 프로세스 + 입력/음향 회귀
.\scripts\verify_coop.ps1 -Render        # 숨김 GPU 창 + PNG
```

프로젝트 첫 실행 전 import가 필요하다. `OPEN_PROJECT.cmd`로 프로젝트를 연 뒤 실행하거나, 동봉 console 실행 파일에 `--headless --editor --path game --import --quit`을 전달한다. 기본 UDP 포트는 24570, 자동 검사는 24571이다. 다른 PC와는 같은 LAN에서 동일 파일 버전을 사용한다. Windows 네트워크 허용이 필요한 경우 사용자가 직접 확인한다.

WASD 이동, 마우스 왼쪽 조준 사격, Space 표적 조준 사격, Esc 연결 종료. 접속 화면의 포트는 변경할 수 있다. **표적 검증 씬에는 하린·퓨즈 임무·LLM·협동 저장이 아직 연결되지 않았다.**

## 검증 경계와 다음 작업

자동 검사 결과와 실행 증거는 `evidence/coop_stage_20261106/`에 정리한다. 기존 미커밋 증거는 덮어쓰지 않고 `runtime/coop_stage_20261106/check/`의 복사본에서 실행했다.

- 기존 메인 임무 기본 251개, GPU UI 81개와 자동 임무 완료를 재확인했다.
- 새 검사는 실제 ENet 두 프로세스의 접속·각자 이동·실제 탄환 피해·양쪽 탄약/적중 결과·잘못된 입력 거부·연결 종료·재접속·초기화를 확인한다. 짧은 클릭/Space, UI 오발 방지, 없는 호스트 접속, 음향 이벤트도 별도로 검사한다.
- 최종 결과: 호스트 14 + 클라이언트 18 + 입력/음향 11 = **43/43**. 헤드리스와 숨김 GPU에서 각각 통과했고 최종 오류/종료 경고는 없다. 헤드리스에서는 음향 이벤트/리소스를 검사하고 장치 재생을 건너뛴다. GPU 자동 검사도 Dummy 오디오를 사용하므로 실제 청취 검증은 아니다.
- 초기 GPU 검사는 잘못된 입력 세 개를 같은 프레임에 전송해 unreliable_ordered 채널에서 이전 패킷이 생략되는 경우 실패했다. 검사에서 각 거절 응답을 받은 뒤 다음 패킷을 보내도록 보완했다. 처음 실패 로그도 보존한다.
- 화면 조작 중단 전 접속 메뉴에서 방 생성/참가 버튼과 실제 연결을 확인했다. 짧은 클릭이 누락되는 점을 발견해 이벤트를 보관하도록 수정했다. 수정 이후 확인은 합성 입력·실제 물리/통신 검사이며 추가 화면 조작은 하지 않는다.
- 짧은 입력 검사에서 종료 직전 OGG 재생의 정리 경고를 발견했다. 음성 종료 시 스트림을 중단/해제하고 헤드리스는 장치를 사용하지 않게 정리했다. 최초 경고 로그도 보존한다.
- 실제 두 PC LAN, 장시간/손실·지연 환경, 사람 플레이·효과음 청취, 메인 임무 전체 협동은 미검증이다. AI 코드는 바꾸지 않아 이번에는 LocalAI 검사를 반복하지 않는다.

다음은 두 PC LAN 확인과 공통 무기 데이터·탄창/재장전·출격 전 하린 무기 선택이다. LAN 확인이 지연되어도 이 싱글플레이 작업을 진행한다. 메인 임무에 협동을 연결하는 작업은 별도 2일 상한을 유지한다.
