## 동작과 작은 설계 선택

- `치료해줘` → 자원/체력/실행 가능성 검사 → 공통 실행기 접근 시작 → “잠깐만, 내가 갈게.” 실제 도착에서 체력 증가/키트 소비 → “됐어. 움직일 수 있겠어?” 키트가 없으면 “치료 키트가 다 떨어졌어.” 요청 수락과 실제 효과를 구분한다.
- `따라와`는 동행, `여기서 기다려`는 현재 위치 경계다. 대기는 명시적 follow 또는 맵/회차 전환까지 유지한다. 긴급 지원은 잠시 우선하고 종료 후 대기 위치로 돌아간다. 단순 손전등 전달은 wait를 덮어쓰지 않는다.
- `패널 같이 누르자`만으로 실행/개방하지 않는다. 플레이어가 한쪽 패널을 실제로 잡아야 지원 후보가 생기며, 반대편 도착·동시 유지 1초·세 쌍 비프 절차를 그대로 사용한다.
- `CharacterBody2D`의 마스크 5는 기존 벽(1)/가구(4)를 사용한다. A*는 활성 방의 `RoundedObstacle` 발밑 영역을 읽고 NPC 반경에 맞춰 확장한다. 도달 불가 목표에는 순간 이동하지 않으며 주기/막힘/맵 전환 시 다시 계산한다. NPC가 플레이어를 물리적으로 가두지 않도록 NPC 레이어는 0이다. 탄환/적 경로의 새 장애물 판정으로 확대하지 않았다.
- 위협 표적은 사망/범위 이탈 또는 유지 시간 이후 아주 가까운 새 위협으로 전환한다. 기본 대형은 후방 한쪽이며 위협과 진로 겹침이 있을 때만 목표를 조정한다.
- 100 긴급 경고, 60 질문/명령 응답, 30 행동 결과, 10 자동 잡담 순위다. 동일 행동의 시작 발화는 종료 발화가 교체한다. 최대 4개 대기 발화는 10초/epoch/현재 사실 조건으로 제한한다. 시스템 안내는 대사/대화 기억에 넣지 않는다.
- 하린 전용 최소 자동 장전이며, 플레이어 무기 체계 전체를 바꾸지 않았다. 20발 + 예비탄 40발, 1.6초 장전, 공용 보급품 1개 → 10발, 비상 탄약함 → 플레이어 10/하린 예비탄 20이다. 자원을 무한 생성하지 않는다.
- 플레이어 탄약이 0이거나 플레이어 보급이 진행 중이면 NPC가 마지막 공용 보급품을 먼저 소비하지 않는다. 모든 탄약/예비탄/보급/회수 경로가 소진되고 적이 남아 있으면 명확한 임무 실패로 전환한다.
- 다운 후 플레이어가 가까이 E를 누르면 공용 키트 1개로 체력 35 소생한다. 키트가 없으면 플레이어가 살아 있어도 실패로 전환해 재도전한다. 기존 보관함/퓨즈 조건을 우회하지 않는다.
- 문맥 창 2048 → 4096, 온도 0.3 → 0.15, 문답 저장 3 → 8개, 프롬프트 이력 850자 제한이다. 캐릭터 취향은 따뜻한 김치볶음밥, 식사 배경은 출발 전 식사 완료다. 과거 식사 메뉴는 설정하지 않았다. 임무 중 과거 사건은 실제 공동 사건 기록만 사용한다.
- 프롬프트 버전은 `companion_v2.1_validated_context_order`. 잘못된 초안은 원문과 사유를 로그에 남기고 같은 모델에 한 번 재생성한다. 두 번째도 부적합하면 오류이며 다른 제공자/고정 문장으로 성공을 대신하지 않는다. 명령 영수증은 `actual_model=common_executor`, `dialogue_method=executor_receipt`로 모델 응답과 구분한다.
- 감정 대화는 짧은 공감 지시와 관련 감정 이력만 사용한다. 게임 안내 문장의 존댓말을 복제하지 않도록 임무 사실은 행동/장소/보유 여부 구조로 전달한다. 음식 질문의 메뉴 답변이나 현재 다음 목표가 올바르면 특정 어미나 전체 후속 임무 문장을 요구하지 않는다.
- main의 기존 이름표 숨김은 유지한다. 실제 상태는 경계 링, 사격 방향 표시, 이동 발자국/작은 흔들림, 지원 시 내린 총구/색·비율, 장전 링, 다운 비율로 구분하며 상태명은 NPC HUD 툴팁에서도 읽을 수 있다.

## 남은 한계와 사람이 확인할 것

- 사람의 WASD/마우스/사격/E를 통한 처음부터 끝까지 완주와 전투 균형, 장시간 플레이는 미검증이다. 자동 임무 검사는 위치·적 상태를 준비한 경우를 포함한다.
- 실제 Microsoft IME, 실제 음향 청취, export 빌드, 두 PC LAN은 이번 검증에 포함하지 않았다.
- 작은 로컬 모델은 임의의 질문에 항상 자연스럽고 사실적인 문장을 보장하지 않는다. 검증기는 특정 위험/반복 패턴을 거르는 제한적 장치이며 완전한 의미 판정기가 아니다. 재생성 실패는 사용자에게 오류로 남는다. 취향이나 과거 사건을 모델이 추가하는지 직접 확인할 필요가 있다.
- A* 격자는 현재 고정 방에 맞춘 보수적인 가구 경계다. 좁은 가구 사이/문턱, 플레이어가 끼어들 때의 이동, 연속 방향 전환/위협 변화는 직접 플레이로 확인한다. 최종 보행/지원 애니메이션은 없고 기존 그림의 회전/색/링/작은 흔들림을 사용한다.
- 예비탄/장전은 하린 전용 최소 경로다. 플레이어 탄창/R 재장전과 출격 전 무기 선택은 별도 작업이다. 소생 비용으로 마지막 키트가 소비된 뒤 다시 다운되면 의도적으로 실패한다.
- 규칙/LLM은 같은 이동·사격·긴급 대응·자원 실행기를 공유하지만, 동일 seed 입력 리플레이나 정식 성능/사용자 비교 실험을 완료한 것은 아니다.
